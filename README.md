# FALCON — коллекция мерча

Интерактивная презентация коллекции FALCON от Izum Design & Production: объекты прокручиваются в очереди,
выбранный подлетает к камере, поворачивается и показывает описание, материалы и брендирование.

Чистые HTML/CSS/JS без зависимостей. Запуск локально: любой статический сервер из корня репозитория,
например `python -m http.server 3020`.

- `data.js` — тексты и характеристики объектов
- `img/turn/NN/` — кадры оборота каждого объекта
- `tools/` — скрипты подготовки кадров из роликов
